# Уведомления

`src/lib/server/notifications/notificationService.ts`

## Что отправляется

| Функция             | Содержание                     | Когда молчит                                |
| ------------------- | ------------------------------ | ------------------------------------------- |
| `sendDailySummary`  | Калории, вода, привычки, траты | День пустой                                 |
| `sendHabitReminder` | Незакрытые привычки на сегодня | Всё закрыто или ничего не запланировано     |
| `sendBudgetWarning` | Потрачено из лимита            | Лимит не задан или израсходовано меньше 90% |

Каждая функция возвращает `boolean` — отправила или промолчала. Сводка из одних
нулей это спам, а не полезное напоминание.

## Расчёты

Берутся из тех же чистых функций, что использует интерфейс:
`calculateNutritionSummary`, `calculateFinanceSummary`, `scheduledHabits`.

Своя арифметика здесь означала бы, что сводка в чате однажды разойдётся с тем,
что человек видит на экране.

Текст собирается отдельно от отправки (`buildDailySummary`), чтобы его можно было
проверить тестом, не поднимая сеть и не тратя вызовы Bot API.

## Планировщик

`POST /api/cron/daily`, закрыт `CRON_SECRET`. Сравнение секрета — `timingSafeEqual`.

Без защиты любой желающий разослал бы уведомления всем пользователям и сжёг
лимиты Bot API.

Вызывается внешним планировщиком. `setInterval` в браузере для этого не годится:
он работает, только пока у кого-то открыта вкладка.

**Vercel Cron** — `vercel.json`:

```json
{ "crons": [{ "path": "/api/cron/daily", "schedule": "0 18 * * *" }] }
```

Vercel шлёт `Authorization: Bearer <CRON_SECRET>` — эндпоинт читает и этот
заголовок, и `X-Cron-Secret`.

**Cloudflare Workers** — Cron Trigger с `fetch` на эндпоинт и заголовком секрета.

**Supabase** — `pg_cron` + `pg_net`, либо scheduled Edge Function.

Ошибка отправки одному пользователю не останавливает остальных: заблокировавший
бота не повод лишить сводки всех прочих. Итог — `{ sent, skipped, failed, total }`.

## Чего не хватает

- **Часовые пояса.** Рассылка идёт одним проходом по всем. Чтобы «итоги дня»
  приходили вечером каждому по его времени, нужно либо запускать крон почаще
  и фильтровать по `users.timezone`, либо хранить желаемое время отправки.
- **Настройки уведомлений.** Поле есть в CloudStorage, но рассылка его пока
  не читает: отписаться нельзя.
- **Дедупликация.** Повторный вызов крона за тот же день отправит сводку второй раз.
