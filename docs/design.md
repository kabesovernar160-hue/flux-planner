# Дизайн Flux Planner

Правила, по которым собран интерфейс. Токены живут в `src/routes/layout.css`,
здесь — как ими пользоваться. Если правило мешает — поменяйте правило здесь,
а не обойдите его в одном компоненте.

## Принципы

1. **Один взгляд — один ответ.** Экран отвечает на один вопрос («как мой
   день?», «куда ушли деньги?»). Всё, что не отвечает на него, — глубже,
   по нажатию.
2. **Действие ближе цифры.** Рядом с каждым числом, которое можно изменить,
   есть способ изменить его в одно касание.
3. **Цвет — это раздел, а не украшение.** Цвет говорит, о чём карточка,
   ещё до того, как прочитан заголовок.
4. **Тихо по умолчанию.** Анимация и свечение — отдача на действие, а не фон.
   Экран в покое не шевелится.
5. **Короче.** Главная — не длиннее двух экранов телефона при обычном дне.

## Цвета разделов

| Раздел                               | Тон      | Класс                         |
| ------------------------------------ | -------- | ----------------------------- |
| Еда, калории, вода                   | янтарный | `tone-amber` / `tone="amber"` |
| Привычки, серии                      | мятный   | `tone-mint` / `tone="mint"`   |
| Деньги, траты, доходы                | голубой  | `tone-sky` / `tone="sky"`     |
| Бренд, план дня, вес, Pro, навигация | лаванда  | без тона (по умолчанию)       |

- Внутри раздела всё красится `text-tone` / `bg-tone/…` / `border-tone/…`,
  а не лавандой. Главная кнопка раздела — тоже в тоне раздела
  (`bg-tone text-on-accent`), лавандовая заливка — только у бренда: FAB, «Pro»,
  онбординг, главные кнопки вне разделов.
- Свечение `shadow-accent` лавандовое — только у лавандовых кнопок. У кнопок
  в тоне раздела тень не лавандовая: `shadow-[0_12px_32px_-16px_var(--fx-tone)]`
  или без тени.
- Предупреждение (перебор лимита, ошибка) — `destructive`, успех — `success`.
  Их не заменяет тон раздела.

## Две темы

Тёмная и светлая, значения — в `:root` и `:root[data-theme='light']`
в `layout.css`. Компонент не знает, какая тема включена, и красится только
токенами:

- Полупрозрачные подложки, волоски, граберы — `bg-ink/[…]`, `stroke-ink/…`,
  а не `bg-white/[…]`: в светлой теме «чернила» тёмные.
- Текст и иконки на залитой кнопке (лаванда, тон, success) — `text-on-accent`,
  а не `text-void`.
- Затемнение под шторкой — `bg-scrim`, тени — `shadow-flat` / `shadow-lift` /
  `shadow-accent` / `var(--fx-shadow-fab)`, блик кромки — `--fx-glass-edge`,
  внутренний блик — `--fx-glass-highlight`.
- Цвета в `oklch(…)` прямо в компоненте не пишем. Нужен новый — заведите
  токен и дайте ему значение в обеих темах.

## Типографика

Шкала — четыре ступени текста и две для цифр. Другие размеры не вводим.

| Роль                         | Класс                                     |
| ---------------------------- | ----------------------------------------- |
| Заголовок экрана             | `PageHeader` (1.75rem, semibold)          |
| Заголовок карточки           | `text-sm font-medium`                     |
| Основной текст               | `text-sm`                                 |
| Вторичный текст, подписи     | `text-xs text-muted-foreground`           |
| Мелкие метки (оси, счётчики) | `text-[11px] text-muted-foreground`       |
| Цифра-герой                  | `fx-num text-5xl`…`text-6xl leading-none` |
| Крупная цифра карточки       | `fx-num text-3xl leading-none`            |

- Все цифры, которые сравнивают или которые меняются, — `tabular` или `fx-num`.
- `text-[9px]`, `text-[9.5px]`, `text-[10px]` не используем: на телефоне это
  нечитаемо. Подписи нижней навигации — `text-[11px]`.

## Геометрия

- Отступ между карточками — `gap-4` (1rem), внутри карточки — `p-5`
  (`GlassCard` по умолчанию), плотные — `padding="sm"`.
- Радиусы — только из шкалы: `rounded-card` у карточек, `rounded-xl` у строк
  и полей, `rounded-full` у кнопок и чипов, `rounded-lg` у чипа иконки.
- Чип иконки в заголовке карточки:
  `<span class="grid size-7 shrink-0 place-items-center rounded-lg bg-tone/12">`
  с иконкой `size={15} weight="regular" class="text-tone"`.
- Минимальная мишень касания — 40×40 (`size-10`). Иконка-кнопка меньше —
  только если рядом нет другой кнопки.

## Иконки

phosphor-svelte. `weight="light"` — в строках и кнопках, `regular` — в чипах
заголовков, `fill` — для состояния «включено/выбрано». Эмодзи в интерфейсе не
используем: они приезжают чужим цветом системного шрифта (в сообщениях бота —
можно).

## Движение

- Одна кривая — `ease-flux`. Длительности: 300–500 мс.
- Появление экрана — `fx-rise` лесенкой (`--fx-step`), не больше 6 шагов.
- Нажатие — `active:scale-[0.98]` у широких кнопок, `active:scale-90` у круглых.
- Отдача на успех — хаптика Telegram и короткая (до 600 мс) анимация на самом
  элементе. Конфетти, тряски и бесконечные пульсации — нет.
- `prefers-reduced-motion` выключает всё — это уже сделано в `layout.css`.

## Тексты

Русский, на «вы», без восклицательных знаков в интерфейсе. Пустое состояние —
одна строка пользы и кнопка действия (`EmptyAction`), не «записей нет».
