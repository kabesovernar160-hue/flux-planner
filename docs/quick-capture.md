# Запись без Telegram

Самый короткий путь от мысли до записи: сказать телефону «ужин в 19:00» —
и запись уже в дневнике. Ни чата, ни приложения открывать не нужно.

Это не украшение. Дневники забрасывают не потому, что они плохие, а потому
что каждая запись стоит нескольких действий: разблокировать, найти, открыть,
дождаться, нажать. Кнопка «Действие» на айфоне или двойное касание крышки
убирают все эти шаги разом.

## Как это устроено

```
телефон ──HTTP──▶ POST /api/capture ──▶ разбор моделью ──▶ дневник
          ключ                                │              │
                                              │              └─▶ приложение
                                              └─▶ эхо в чат с ботом
```

Разбирает фразу модель — та же, что в чате и в приложении. Правила
по ключевым словам остались запасным вариантом: без ключа провайдера,
без сети и когда модель не ответила.

Подписи Telegram в этот момент нет и быть не может: Mini App не запущен.
Поэтому у человека есть **личный ключ**, который он один раз вставляет
в «Быструю команду».

Три правила, на которых держится ключ:

1. **В базе только хеш.** Сам ключ показывается ровно один раз, при создании.
   Утёкшая копия базы не открывает доступ к чужим дневникам.
2. **Ключ односторонний.** Им можно записать строку — и больше ничего:
   ни прочитать дневник, ни поменять настройки, ни купить подписку. Цена
   утечки — мусорная запись, а не потеря данных.
3. **Активный ключ один.** Новый отзывает прежний, отзыв — одна кнопка
   в настройках. Список ключей, за которым никто не следит, — это ключ,
   о котором забыли.

## Что понимает

Разбор общий с ботом и приложением: «ужин в 19:00» даёт один результат везде.
Фразу понимает модель, поэтому таблица ниже — примеры, а не список
поддерживаемых шаблонов: «закинул полторы на такси вчера вечером»
разберётся так же.

| Фраза                       | Что получится                          |
| --------------------------- | -------------------------------------- |
| `ужин в 19:00`              | дело на сегодня, 19:00                 |
| `завтра в 8 утра зарядка`   | дело на завтра, 08:00                  |
| `через час позвонить врачу` | дело на сегодня, час от текущего       |
| `в пятницу баня`            | дело на ближайшую пятницу              |
| `потратил 500 на такси`     | трата 500 ₽, категория из названия     |
| `потратил 1.5к на продукты` | трата 1 500 ₽                          |
| `зарплата 90000`            | доход                                  |
| `450 борщ`                  | еда, 450 ккал                          |
| `на обед борщ 450 ккал`     | еда в обед, даже если записано вечером |
| `вес 78,4`                  | взвешивание за сегодня                 |

Чего разобрать не удалось — честно отвечает «не понял»: выдуманная запись
в дневнике хуже отсутствующей.

## Быстрая команда на айфоне

Ключ создаётся в приложении: **Настройки → Запись без Telegram → Создать ключ**.
Скопируйте его сразу — второй раз он не покажется.

1. «Быстрые команды» → новая команда.
2. Действие **«Запросить ввод»** (или **«Диктовать текст»**, если хотите говорить).
3. Действие **«Запросить содержимое URL»**:
   - адрес: `https://ваш-домен/api/capture`
   - метод: **POST**
   - заголовок: `Authorization` = `Bearer ВАШ_КЛЮЧ`
   - тело запроса: **Текст**, внутрь подставьте результат первого действия
4. Действие **«Показать результат»** — чтобы видеть подтверждение.

Записанное приходит ещё и в чат с ботом, вместе с тем, что услышала диктовка:

```
Записал. Трата: Такси — 1500 ₽

Услышал: «закинул полторы тысячи на такси»
         [ Открыть Flux Planner ]
```

Это не дубль уведомления, а ленты ради: распознавание речи ошибается, и по
чату видно, что телефон услышал «полтора», а не «пол-литра». Кнопка под
сообщением открывает приложение — из чата в дневник один тап.

Дальше команда вешается куда удобно:

- **Кнопка «Действие»**: Настройки → Кнопка «Действие» → Быстрая команда.
- **Двойное касание крышки**: Настройки → Универсальный доступ → Касание →
  Касание задней панели → Двойное касание.
- **Siri**: просто назовите команду голосом.
- **Экран блокировки и виджеты**: команда доступна как обычный ярлык.

## Для проверки из терминала

```bash
curl -X POST https://ваш-домен/api/capture \
  -H "Authorization: Bearer ВАШ_КЛЮЧ" \
  -H "content-type: text/plain; charset=utf-8" \
  --data-raw "ужин в 19:00"
```

Ответ: `{"ok":true,"message":"Записал. В план на сегодня: Ужин в 19:00"}`.

Тело принимается и строкой, и JSON-объектом `{"text":"..."}` — в «Быстрых
командах» строкой проще, а собирать JSON руками человек не станет.

Если заголовок задать негде, ключ можно передать параметром:
`/api/capture?key=ВАШ_КЛЮЧ`. Это хуже — адрес с ключом оседает в журналах, —
но лучше, чем невозможность записать.

## Пределы

- 30 записей в минуту на человека и 60 с одного адреса: заведомо больше,
  чем успевает надиктовать человек, и заведомо мало, чтобы утёкшим ключом
  незаметно засыпать дневник.
- 400 символов на запись: это строка для дневника, а не заметка.
- Ключ не читает данные — ответ содержит только подтверждение записи.
